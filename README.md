## 📖 Overview

High employee turnover drains organizational resources, impacts team morale, and incurs significant recruitment and training costs. **Employee Attrition Prediction** is an end-to-end Machine Learning initiative designed to proactively identify employees who are at a high risk of leaving the company. 

By analyzing comprehensive employee-related data, this project translates raw workforce metrics into actionable HR intelligence, enabling targeted retention strategies before the talent is lost.

---

## 🎯 Core Objectives

- **Predictive Power:** Engineer a robust classification model to forecast employee flight risk with high precision.
- **Risk Identification:** Flag high-risk employees to empower HR departments to intervene preemptively.
- **Strategic Insights:** Uncover the driving factors and hidden patterns behind employee dissatisfaction and turnover.

## 🛠️ Tech Stack & Tools

> Standard toolkit utilized in this data science workflow.
- **Data Manipulation:** `pandas`, `numpy`
- **Visualization:** `matplotlib`, `seaborn`, `plotly`
- **Machine Learning:** `scikit-learn`, `XGBoost`, `LightGBM`
- **Environment:** Jupyter Notebook

---

## 🗄️ Dataset Details

The foundation of this project is a robust dataset originally focused on churn, which we are adapting for employee attrition dynamics.

| Attribute | Detail |
| :--- | :--- |
| **Source** | [Kaggle](https://www.kaggle.com/datasets/parthangare/customer-churn-predict-who-will-leave-a-service) |
| **Volume** | 200,000 Records (`employee_churn_200k.csv`) |
| **Target Variable** | `Attrition` (Binary: *Likely to Stay* / *Likely to Leave*) |
| **Domain** | Human Resources / Workforce Analytics |
